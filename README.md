# VibeCoder Ops Bot

---

## ALFA Principle

> **You do not exist until you prove you are worth it.**

No artifact exists outside the sandbox until it proves **source, scope, safety, and value**.

Every artifact must prove:
- **Source** — where did it come from?
- **Scope** — what does it actually touch?
- **Safety** — will it break things, leak data, or cause harm?
- **Value** — does it solve the problem it claims to solve?

Code does not pass without proof.  
An agent does not act without scope.  
An artifact does not leave without validation.  
A result does not exist just because it was generated.

---

## What is this?

**VibeCoder Ops Bot** — not "a bot that does everything", but a bot that manages the full delivery flow for one type of person:

> Someone with an idea, the ability to glue things together, but who gets lost between repo, prompts, tasks, tests, and publishing.

**Not** an AI coder god. A system that turns vibe coding into shipping.

---

## Core Capabilities

### 1. Idea Intake
Drop a chaotic description, screenshots, links, voice notes.  
Bot converts it into: goal, scope, features, risks, stack, checklist.

### 2. Task Breakdown
Not "build the app" — but: auth, database, UI, payments, deploy, tests.

### 3. Repo Brain
Bot reads the repo and reports plainly: what exists, what is broken, what is missing, what not to touch.

### 4. Model Router
Decides autonomously which model to use:
- Claude → refactor / codebase analysis
- ChatGPT → agentic flows / images / research
- Local model → cheap tasks
- Whatever the user plugs in

### 5. Anti-Vibe-Coding Guard
The killer feature. Bot says:
- "You don't understand this"
- "Validation is missing here"
- "This only works on demo"
- "Don't publish without tests"
- "This code was generated but is not maintained"

It doesn't just help — it stops stupid.

### 6. Discord / Telegram / Mail Commander
User asks: "what's left today?", "what's blocking release?", "give me a prompt for the fix", "summarize branches" — bot answers with project memory.

### 7. Publish Mode
Produces: README, landing copy, changelog, pricing draft, GitHub cleanup, deploy checklist.

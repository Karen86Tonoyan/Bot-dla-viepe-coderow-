# VibeCoder Ops Bot

> **ALFA Principle:**
> *You do not exist until you prove you are worth it.*
>
> Every artifact must prove:
> - **source** — where did it come from?
> - **scope** — what is it responsible for?
> - **safety** — does it introduce risk?
> - **usefulness** — does it deliver value?

No artifact exists outside the sandbox until it proves source, scope, safety, and value.

---

## What is this?

**VibeCoder Ops Bot** is not a bot that does everything.  
It is a bot that turns **vibe coding into shipped products** — for solo builders, founders without a team, and people caught between 20 ideas and 0 completed projects.

It is built around one idea:

> *chaos → shipped product*

---

## Core Functions

### 1. Idea Intake
User drops a chaotic description, screenshots, links, or voice notes.  
Bot converts it into:
- goal
- scope
- features
- risks
- stack
- checklist

### 2. Task Breakdown
Not "build the app" — instead:
- auth
- database
- UI
- payments
- deployment
- tests

### 3. Repo Brain
Bot reads the repository and reports:
- what already exists
- what is broken
- what is missing
- what should not be touched

### 4. Model Router
Bot decides which model to use:
- Claude → refactoring / codebase analysis
- ChatGPT → agentic flows / images / research
- local model → cheap, repetitive tasks
- any model the user plugs in

### 5. Anti-Vibe-Coding Guard
The killer feature. Bot says:
- "you don't understand this"
- "validation is missing here"
- "this only works in demo"
- "don't publish without tests"
- "this code is generated but unmaintained"

It does not just help — it **stops bad decisions**.

### 6. Commander (Discord / Telegram / Email)
User asks:
- "what's left for today?"
- "what is blocking the release?"
- "give me a prompt to fix this"
- "summarize branches"

Bot responds with project memory.

### 7. Publish Mode
At the end, bot produces:
- README
- landing copy
- changelog
- pricing draft
- GitHub cleanup checklist
- deploy checklist

## ALFA Principle in Practice

| Rule | Meaning |
|------|---------|
| Code does not pass without proof | No merge without validation |
| Agent does not act without scope | No task without defined boundaries |
| Artifact does not leave without validation | No deploy without passing the gate |
| Result does not exist just because it was generated | Generation ≠ correctness |
